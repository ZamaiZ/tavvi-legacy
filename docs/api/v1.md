# Express endpoints

The Next.js application reads and writes product data through its server-side DAL and Supabase. Express is not the Web product API; it supports health monitoring and Web Push delivery.

| Method | Path | Access | Purpose |
| --- | --- | --- | --- |
| GET | `/healthz` | Public | Service health response |
| POST | `/api/v1/internal/push/deliver` | Server key in `x-server-key` | Schedule delivery of pending browser push notifications |

The push endpoint responds with HTTP 202 after scheduling work. It does not wait for providers to deliver. The database validates `APP_SERVER_KEY` again when claiming notifications. Delivery uses only Web Push subscriptions and the server-held VAPID private key.

No user login, mobile session, restaurant, invitation, or notification-center routes are served from Express. Those authenticated Web flows remain in Next and Supabase.
