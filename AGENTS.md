# Repository instructions

## Project scope

This repository contains an Expo and React Native application in `apps/mobile` and an Express API in `apps/backend`. The Next.js application is maintained separately. Prioritize mobile-first patterns, performance, and cross-platform compatibility.

## Commands and tests

- Do not run Git commands, lint, typecheck, build, or test commands.
- Do not add or run tests.
- Use static inspection to verify changes and clearly report what could not be executed.
- Use `pnpm` for this workspace. Workspace dependency changes belong in the relevant app manifest and the root lockfile.

## Expo documentation

Expo changes between SDK releases. Before changing an Expo, EAS, or React Native API:

1. Read the Expo major version in `apps/mobile/package.json`.
2. Read its versioned documentation at `https://docs.expo.dev/versions/v<major>.0.0/`.
3. Read `https://docs.expo.dev/llms.txt` and follow its links to the specific API reference.

Do not rely on remembered API names or behavior.

## Navigation and routing

- Use Expo Router for navigation. Routes live in `apps/mobile/src/app/`; `_layout.tsx` files define navigators.
- Keep non-route components, hooks, and utilities outside `src/app/`.
- Import `Link`, `router`, and `useLocalSearchParams` from `expo-router`.
- Reference: `https://docs.expo.dev/router/introduction.md`.

## Native projects

- If `apps/mobile/ios/` and `apps/mobile/android/` do not exist, they are generated by Continuous Native Generation. Do not create or edit them manually; configure native behavior in `apps/mobile/app.json` and config plugins.
- Expo Go includes only its bundled native modules. A library with native code requires a development build.
- Prefer recommended Expo modules over third-party libraries. Check available skills before adding dependencies.

## EAS

Use EAS for cloud builds, submissions, and over-the-air updates. Keep `eas.json` and `app.json` in `apps/mobile/`, and run EAS commands with `apps/mobile` as the project root. Reference: `https://docs.expo.dev/eas/index.md`.
